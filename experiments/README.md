# Experimentos

Esta pasta organiza os códigos e artefatos por coleção experimental.

- `historical/`: registro amplo de 16.650 execuções.
- `controlled/`: ID, LODO, remoção fixa e classificador de origem.
- `robustness/`: análises posteriores de robustez.
- `exploratory/`: testes que não integram os resultados principais.
- `configs/`: cópia das configurações comuns.

As coleções são distintas e não devem ser somadas como uma única grade.
Resultados consolidados ficam em `results/`.
Use os READMEs internos e preserve sementes, alvos e vistas ao reproduzir.
Treinamentos não são necessários para conferir as tabelas já salvas.
