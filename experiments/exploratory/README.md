# Experimentos exploratórios

Material preservado para procedência, fora das conclusões principais.

As três baterias comparam subconjuntos de dez atributos no CatBoost.
Há um top-10 estável, um grupo SQLi e um grupo lexical.
Os manifests registram hashes, caminhos históricos e configurações.
Os caminhos absolutos desses manifests foram preservados para não romper IDs.
`COMPARACAO_TOP10_GRUPOS_2026-10-15.md` resume a comparação.
Os CSVs contêm resultados por alvo e os atributos selecionados.
Não use estes resultados como seleção de hiperparâmetros no alvo.
Eles não integram as tabelas e figuras finais do artigo.
Novas explorações devem ser mantidas separadas das coleções principais.
