# Configurações dos experimentos

Esta pasta preserva a cópia organizada dos YAMLs usados pelo pipeline.

- `datasets.yaml`: entradas e famílias de procedência.
- `models.yaml`: parâmetros fixos dos classificadores.
- `seeds.yaml`: sementes experimentais.
- `experiments.yaml`: cenários e grades.
- `paths.yaml`: caminhos relativos esperados.

As versões ativas ficam em `config/`.
Compare hashes antes de substituir uma configuração histórica.
Não inclua dados sensíveis, cookies ou destinos de campanha.
Os scripts devem ser executados a partir da raiz do repositório.
