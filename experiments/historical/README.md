# Coleção histórica

Contém a cópia organizada dos estágios que produziram o registro histórico.

O registro possui 16.650 execuções utilizáveis.
Delas, 13.170 correspondem à composição de fontes.
Também há avaliações entre pares, ablações e cenários ID/LODO.
`run_all.py` despacha os estágios numerados de `00` a `17`.
Cada subpasta preserva seu script e uma instrução curta de uso.
Os resultados compactos estão em `results/runs/historical/index/`.
As versões RAW e CANONICALIZED históricas ficam em `datasets/processed/`.
A coleção histórica não possui snapshot individual de código para cada run.
Consulte `provenance/run-lineage/` para a cobertura registrada.
