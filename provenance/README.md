# Integridade e plano de execução

Esta pasta contém somente:

- `artifact-checksums/repository_files.csv`: tamanho e SHA-256 dos arquivos
  versionados no Git;
- `run-lineage/controlled_plan.json`: plano da coleção controlada.

Os manifestos das bases ficam em `datasets/metadata/` e
`datasets/processed/manifest.csv`.
