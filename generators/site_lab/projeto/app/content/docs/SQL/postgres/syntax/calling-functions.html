Calling Functions

Functions are invoked with parentheses after the function name. Arguments can be positional, named with =>, or omitted when a default value is declared.

SELECT substring('postgresql' FROM 1 FOR 4);
SELECT make_interval(days => 2, hours => 6);
SELECT date_trunc('month', created_at)
FROM events;

Named notation is useful when a function has several optional parameters because the call states which argument receives each value.
