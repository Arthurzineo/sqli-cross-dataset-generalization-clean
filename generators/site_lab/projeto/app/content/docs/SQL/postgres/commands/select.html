SELECT

SELECT reads rows and expressions from one or more sources. A query can project columns, join relations, filter rows, group results, sort output, and limit the result set.

SELECT c.customer_id,
       c.name,
       sum(o.total) AS lifetime_value
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.customer_id
WHERE o.status = 'paid'
  AND o.created_at >= date_trunc('year', current_date)
GROUP BY c.customer_id, c.name
HAVING sum(o.total) > 1000
ORDER BY lifetime_value DESC
LIMIT 20;

The FROM clause identifies sources, WHERE applies row-level conditions, and GROUP BY creates groups for aggregate functions. Use parameter binding in application code for values such as dates, status, and limits.

SELECT id, email
FROM accounts
WHERE email ILIKE $1
ORDER BY id
OFFSET $2 LIMIT $3;

A SELECT query can also use DISTINCT, subqueries, common table expressions, window functions, and set operations such as UNION.
