VALUES

VALUES constructs an inline table of rows. It can be used alone, inside a common table expression, or as the source for an INSERT statement.

VALUES
  (1, 'open'),
  (2, 'closed'),
  (3, 'pending');

Assign names to the derived columns when a query needs to reference them.

SELECT status.code, status.label
FROM (VALUES (1, 'open'), (2, 'closed'))
     AS status(code, label);
