UPDATE

UPDATE changes existing rows. A WHERE clause identifies which rows change; without it, every row in the target table is updated.

UPDATE orders
SET status = 'shipped',
    shipped_at = now()
WHERE order_id = 42
RETURNING order_id, status, shipped_at;

An UPDATE ... FROM statement can use another relation while calculating new values.

UPDATE products AS p
SET price = p.price * d.multiplier
FROM discounts AS d
WHERE d.category_id = p.category_id
  AND d.active = true;
