COPY

COPY transfers table data to or from a file or standard input/output. It is commonly used for efficient bulk loading and export.

COPY products (sku, name, price)
FROM STDIN WITH (FORMAT csv, HEADER true);

Use \copy in the psql client when the client, rather than the database server, should access the local file system.

COPY (SELECT order_id, total FROM orders WHERE status = 'paid')
TO STDOUT WITH (FORMAT csv, HEADER true);
