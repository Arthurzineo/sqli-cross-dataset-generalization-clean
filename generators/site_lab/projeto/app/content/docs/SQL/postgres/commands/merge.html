MERGE

MERGE compares a source relation with a target relation and performs conditional INSERT, UPDATE, or DELETE actions in one command.

MERGE INTO inventory AS target
USING incoming_stock AS source
ON target.sku = source.sku
WHEN MATCHED THEN
  UPDATE SET quantity = target.quantity + source.quantity
WHEN NOT MATCHED THEN
  INSERT (sku, quantity) VALUES (source.sku, source.quantity);

The join condition should identify the intended target row. Each source row can trigger at most one WHEN action.
