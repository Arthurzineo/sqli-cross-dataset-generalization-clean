String Constants

Ordinary string constants use single quotes. To include a single quote inside one, write it twice. Escape string syntax is available with the E prefix when an escape sequence is needed.

SELECT 'O''Brien' AS author;
SELECT E'first line\nsecond line' AS note;
SELECT '100%'::text AS pattern;

Parameters supplied by an application should be bound values rather than concatenated into SQL text, even when the final query contains a string constant.
