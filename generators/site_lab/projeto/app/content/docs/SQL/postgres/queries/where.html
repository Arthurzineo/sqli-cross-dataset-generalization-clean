WHERE

WHERE filters rows before grouping. Conditions may use comparisons, boolean logic, ranges, pattern matching, and subqueries.

SELECT order_id, total
FROM orders
WHERE status = 'paid'
  AND total > 100
  AND created_at >= current_date - interval '30 days'
  AND customer_id IN (SELECT customer_id FROM vip_customers);

Parentheses make AND and OR grouping clear. Bind application values as query parameters rather than concatenating them into SQL.
