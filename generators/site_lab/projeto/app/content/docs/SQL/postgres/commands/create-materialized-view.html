CREATE MATERIALIZED VIEW

CREATE MATERIALIZED VIEW stores the result of a query physically. It is useful for expensive summaries that can be refreshed on a schedule.

CREATE MATERIALIZED VIEW customer_order_totals AS
SELECT customer_id, count(*) AS order_count, sum(total) AS total_spend
FROM orders
GROUP BY customer_id;

REFRESH MATERIALIZED VIEW customer_order_totals;

Unlike a normal view, a materialized view can become stale until it is refreshed.
