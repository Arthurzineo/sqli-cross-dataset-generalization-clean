pg_sleep

pg_sleep(seconds) pauses the current PostgreSQL session for the requested interval. It is useful only for controlled maintenance or test scenarios and should be used cautiously because it occupies a connection.

SELECT pg_sleep(0.5);
SELECT now() AS before_sleep, pg_sleep_for(interval '1 second'), now() AS after_sleep;

This page documents a normal PostgreSQL function; applications should not expose arbitrary execution of SQL functions to untrusted input.
