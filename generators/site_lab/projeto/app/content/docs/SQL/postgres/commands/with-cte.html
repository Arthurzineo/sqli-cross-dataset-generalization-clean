WITH and Common Table Expressions

A WITH clause defines one or more named common table expressions (CTEs) for a following SELECT, INSERT, UPDATE, DELETE, or MERGE command.

WITH recent_orders AS (
  SELECT customer_id, total
  FROM orders
  WHERE created_at >= current_date - interval '30 days'
)
SELECT customer_id, sum(total) AS monthly_total
FROM recent_orders
GROUP BY customer_id;

Add RECURSIVE for hierarchical traversal. Data-modifying CTEs can pass rows between commands by using RETURNING.
