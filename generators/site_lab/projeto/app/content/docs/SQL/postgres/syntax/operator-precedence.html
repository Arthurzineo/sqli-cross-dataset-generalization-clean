Operator Precedence

PostgreSQL evaluates operators according to precedence rules. Parentheses make the intended grouping explicit and should be used when arithmetic, comparison, and boolean operators are combined.

SELECT (subtotal + tax) * quantity AS amount
FROM invoice_lines
WHERE (paid = false OR due_date < current_date)
  AND cancelled = false;

In particular, NOT, AND, and OR do not have equal precedence. Parentheses prevent an ambiguous WHERE condition from changing its meaning.
