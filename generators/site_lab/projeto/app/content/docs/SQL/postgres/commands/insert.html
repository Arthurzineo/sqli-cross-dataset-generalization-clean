INSERT

INSERT adds rows to a table. Supply a column list to make the mapping from values to columns explicit, and use RETURNING when the new row must be read immediately.

INSERT INTO customers (name, email, created_at)
VALUES ('Ada Lovelace', 'ada@example.test', now())
RETURNING customer_id, created_at;

PostgreSQL can insert multiple rows or insert the output of a SELECT. Conflict handling is available with ON CONFLICT.

INSERT INTO inventory (sku, quantity)
VALUES ('book-001', 4)
ON CONFLICT (sku)
DO UPDATE SET quantity = inventory.quantity + EXCLUDED.quantity;
