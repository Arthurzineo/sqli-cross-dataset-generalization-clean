Identifiers and Keywords

Identifiers name tables, columns, schemas, and other database objects. Unquoted identifiers are folded to lower case; double quotes preserve spelling and case.

CREATE TABLE sales_order (
  order_id bigint PRIMARY KEY,
  created_at timestamptz NOT NULL
);

SELECT "OrderId"
FROM "SalesReport";

Keywords such as SELECT and JOIN have syntactic meaning. Prefer ordinary lower-case identifiers unless quoted names are necessary.
