Value Expressions

A value expression produces a scalar value. PostgreSQL accepts constants, column references, function calls, operators, casts, and subqueries where an expression is expected.

SELECT price * quantity AS line_total,
       created_at::date AS order_date
FROM order_lines
WHERE quantity + 1 > 3;

Expressions can appear in a SELECT list, a WHERE condition, an ORDER BY clause, and many command arguments.
