# Tabelas

Tabelas consolidadas para o artigo e para a auditoria de resultados.

`historical/` reúne os resumos A–K da bateria histórica.
`manuscript_analysis/` contém análises detalhadas por seção e QP.
Os formatos CSV e Parquet equivalentes são mantidos quando disponíveis.

As tabelas principais usam F1 da classe ataque.
Resumos macro dão o mesmo peso a cada alvo após agregar sementes.
Arquivos de traceabilidade registram fontes e filtros analíticos.
O README principal liga as tabelas finais aos scripts geradores.
Não trate arestas de coalizão como unidades independentes de inferência.
Exemplos de erro não incluem mais texto bruto de requisições.
