# Analysis Method — 4.6 / 5.3

Principal metrics_source, threshold escolhido na validação de origem. PR-AUC=average_precision_score (não trapezoidal). Seeds resumidas dentro de cada condição. Gap=M_ID−M_OOD; razão F1_OOD/F1_ID, indefinida se denominador zero. Cenários não são combinados. SOURCE_AWARE_VALIDATION documenta somente os domínios e early stopping realmente existentes.

O que/por quê: Generalização, para RQ1. Foram usados os arquivos e IDs mapeados em SOURCE_FILES.parquet; pilotos/falhas/não aplicáveis em M04.01/tables/excluded_runs.csv. Não se imputam métricas ausentes. Os dados não foram usados para escolher novamente modelos ou thresholds. Artefatos por linha permitem recuperar os filtros exatos e seeds.
