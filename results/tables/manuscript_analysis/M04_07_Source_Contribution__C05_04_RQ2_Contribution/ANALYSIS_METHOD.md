# Analysis Method — 4.7 / 5.4

O que/por quê: Contribuição das fontes, para RQ2. Foram usados os arquivos e IDs mapeados em SOURCE_FILES.parquet; pilotos/falhas/não aplicáveis em M04.01/tables/excluded_runs.csv. Não se imputam métricas ausentes. Os dados não foram usados para escolher novamente modelos ou thresholds. Artefatos por linha permitem recuperar os filtros exatos e seeds.
