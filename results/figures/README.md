# Figuras derivadas

Gráficos de dados, validações e rastreabilidade visual.

`data_plots/` contém os gráficos de dados e seus artefatos de validação.
Eles preservam valores plotados e relatórios de validação.

Os gráficos são derivados das tabelas em `results/tables/`.
`analysis/render_final_manuscript_figures.py` renderiza a série controlada.
`analysis/manuscript_additional/` cobre fontes e atributos recorrentes.
Consulte o README principal para a numeração completa e reduzida.
