# Verificação local

Saídas pequenas produzidas durante a montagem e conferência do pacote.

`lodo_macro_regenerated.csv` recompõe a tabela macro a partir dos resultados.
`verification.md` registra a comparação com os números do manuscrito.
Nenhum modelo foi retreinado para produzir esta pasta.

Esses arquivos são evidência de consistência, não uma coleção experimental.
As fontes científicas permanecem em `results/runs/` e `results/tables/`.
Use `tools/verify_saved_outputs.py` para verificações equivalentes.
Diferenças futuras devem ser investigadas antes de atualizar o artigo.
Preserve a definição de agregação usada no estudo.
